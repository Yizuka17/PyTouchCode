# PyTouchCode 界面约定

使用原生 WinUI 控件。常用操作放在工具栏，编辑区占据主视图。

配色采用 Windows Terminal 内置方案数据。编辑器与终端分别记忆深浅模式的选择。行号栏和折叠栏使用当前编辑器背景，终端不显示代码辅助栏。

界面、编辑器、终端分别设置字体、字号与字重。字体列表读取本机字体。设置保存后应用，取消不改动当前配置。

工具栏使用 Fluent System Icons。文件树与标签页使用 Material Icon Theme，文件夹使用 Fluent 文件夹图形；完整 SVG 视口参与缩放。文件类型变化后刷新标签图标。

文案只保留标签、必要状态和错误提示，不使用装饰性分隔点。
