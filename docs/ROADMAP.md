# 后续计划

## 发布前阻塞项

- 在 Windows 11 Surface 实机验收横向选择、纵向惯性、选择手柄、双指缩放、120 Hz、Surface Pen 与触摸键盘。
- 在真实 Pyboard / MicroPython 开发板上验收 REPL、长任务中断、软重启、main.py 上传下载和异常断连恢复。
- 在管理员测试设备建立开发证书信任，安装当前 MSIX 并验证启动；在无开发工具的干净 Windows 11 机器验证自包含分发。
- 恢复可用的截图 / 录屏验证环境，检查明暗主题、窄窗口、设置对话框、补全菜单与高对比度；完成独立视觉评审。

## 终端与编辑体验

- 加入 ConPTY 与真正的 VT 终端屏幕缓冲，补齐全屏应用、Ctrl+C、光标操作与 ANSI 颜色。
- 长按选择词、手柄放大镜、触控边缘自动滚动的调参；替换临时惯性计时器为经过实测的高刷新率实现。
- 字体连字开关；配色、字体列表、行高与字重设置已在 0.1.3 完成。
- 多标签批量关闭、恢复会话、文件变更提示、可取消的超大目录加载。编辑器分栏属于需求允许后续实现的项目。

## 智能开发与设备

- 多文件 LSP 工作区、语义诊断、自动导入、MicroPython 设备 API stubs 和板型配置。
- DAP 异常细节面板、条件断点、watch 表达式、调试 stdin 和更多线程选择。
- 数组 dtype / shape 专用查看器、表格与绘图查看器，避免将超大变量全部载入 UI。
- 设备目录导航、批量传输、进度取消与恢复、USB 到达 / 拔出事件通知。

## 发布与性能

- 在目标机器记录冷 / 热启动、首字输入延迟、滚动帧时间、空闲 CPU 唤醒和常驻内存基线。
- 评估原生组件实际可支持的渲染选项，提供有实测依据的软件回退；不增加大型机器学习运行库依赖。
- 受信任公开签名与应用本体更新渠道；迁移到后续 .NET LTS 前回归 WinUIEdit 的 ABI 与 XAML 行为。
